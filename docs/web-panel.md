# Web 面板

“通知 → 飞书卡片操作”按已有飞书应用群显示授权和长连接状态，read/config 只读、admin 可显式启用或撤销。页面说明群原消息收件人的两种有限权限，连接状态每五秒刷新，离开即取消请求；真实订阅与真人点击仍 Pending。接入和作用范围见 [卡片动作](card-actions.md)。

构建：Go 1.27、Node 22.22.2+（22.x）和 pnpm 11.21.0。执行 `scripts/build.ps1`，先安装锁定的前端依赖并构建，再以 webui 标签将产物嵌入 `bin/lgmon.exe`。运行编译后的 exe 不需要 Node。前端产物与 node_modules 不提交；pnpm 11 的项目设置在 web/pnpm-workspace.yaml，缓存与状态放在仓库的 dev-home/，不是 .npmrc。

在监控器运行时打开 `http://127.0.0.1:7444/`。只有直接回环访问的首页携带仅限本机的只读会话，远程首页不携带令牌。手机使用监控器允许的地址访问，在页面填写本人创建的令牌；监听和令牌创建见 [CLI](cli.md)。页面不改变监听或服务配置；只有在“内网”页打开内网可见时，lgmon 会为内网共享端口添加一条防火墙入站规则，见 [内网共享](teams.md#网络和安全)。

访问令牌默认只保存在当前标签页会话，不写 URL 或日志；粘贴令牌时选“这台电脑上一直用”才保存在这个浏览器的 localStorage，以后新开的窗口自动带上，设置“这个网页的权限”里可以忘掉它（U15）。主题偏好保存在 localStorage。服务重启使本机会话失效时重新加载首页；远程令牌失效会回到连接页面。右上角“只读 / 可配置 / 管理员”来自实际认证响应的 X-Lgmon-Scope，不能作为服务端授权依据。read 只能查看，config/admin 才显示可执行的确认与静音；后端仍逐请求检查权限。

使用 http: 且访问主机不属于回环或 Tailscale 网段时，登录表单前及页面顶部显示“正在通过不加密的 HTTP 在局域网提供面板，同一网络里的人可能截获令牌。建议改为只监听 Tailscale 地址”。按浏览器地址判断，不依据后端的 publicBaseUrl；HTTPS、localhost、IPv4/IPv6 回环和 Tailscale 地址不提示，其他 DNS 名称提示。HTTPWarning 组件只展示地址风险，不修改监听配置。

## 小窗口（U6-01）

lgmon 以系统服务运行时不再自己打开小窗口：以前服务一启动就以 SYSTEM 身份在后台拉起 lgmon-window，WebView2 不能在系统账户下运行，只弹出“Microsoft Edge 无法读取和写入其数据目录”，这个窗口进程还会在卸载时占住文件。lgmon-window 也拒绝在系统账户或服务会话里启动。`#/start` 是打开 lgmon 时看到的页面，在 lgmon 自己的窗口里显示（U7，见 [命令行](cli.md#打开-lgmonu6)），一屏放下，只有服务很多时服务列表这一段滚动：顶部是 lgmon 标识和“运行中”；大标题一句话结论（一切正常 / N 个服务异常 / N 个服务还没有数据 / 还没有在监控服务），下面一行是服务数、子服务数、告警数和这台电脑；服务卡片最多列 6 个，异常的在前并写原因，正常的写 24 小时可用率，其余“还有 N 个”；有子服务的服务右侧是一个折叠按钮：每个子服务一格小色条（最多 6 格）加数量，有异常时写“N 异常”。子服务全部正常时默认收起，有一个异常就自动展开，点按钮随时展开或收起并记住选择；展开后一条细竖线连着，字小一号，异常的在前、各写各的状态，超过 6 个时先显示 6 个和“再显示 N 个”；Agent 卡片在下方（还没有服务时是主角，有服务后变成安静的一张）：左上是品牌色的小图标，标题和一句说明，下面是黑色的“复制这段话”、可展开的“显示这段话”（展开后是一个对话气泡样式的等宽文本框）和一排常见 Agent 的图标，最下面一条是 Agent 连接状态；复制后按钮变绿写“已复制”，卡片底部是现在连着的 Agent：每个一枚带图标的小标签和三格信号，同一种开了几个写“×2”；最底部是黑色的“打开看板”和“告警”“设置”，都在默认浏览器里打开。浏览器里已经开着 lgmon 页面时（本机打开的），点“打开看板”“告警”“设置”不再新开页面：那个页面跳到对应页、刷新数据，那个浏览器窗口被带到前面（最小化的会还原）；只有找不到这样的窗口（例如 lgmon 页面不是所在窗口的当前标签）时才新开一个。（U12）背景是柔和的彩色光晕，异常时偏暖。服务列表读不到时显示“正在读取…”或“暂时读不到状态”并自动重试，不会误说“还没有在监控服务”。

更新（U8）：lgmon 小窗口打开时自动从 [GitHub 公开发布页](https://github.com/LFenX/lg-monitor/releases/latest) 获取最新正式版本，再读取该版本的安装器校验值。默认检查的 GitHub REST API 请求数为零。检查、“已是最新版本”和检查失败只在窗口底部显示为一行小字（“v x.y.z · 检查更新”“检查更新失败，重试”），点它重新检查；只有真正有事可做时（有新版本、正在下载、已下载好、下载失败）窗口上方才出现更新卡片，例如“lgmon x.y.z 可以更新了”。更新代码按需加载，只在 lgmon 自己的窗口里下载，浏览器里的看板不加载，“更新内容”打开发布说明。“下载更新”显示进度，下好并通过 SHA-256 校验后可点“重启并更新”。安装器以更新模式沿用角色和数据目录，完成后重新打开小窗口。下载失败时可重试。开发版不检查更新。普通浏览器的“关于 lgmon”显示版本，并提示在小窗口里更新。双击 `lgmon.exe`、从开始菜单选择“lgmon”、点击托盘“打开 lgmon”或使用安装完成页均可打开小窗口。见 [命令行](cli.md#打开-lgmonu6)。

## 导航与主线（U4）

外观是暖白底（深色为暖灰）、衬线标题、陶土橙强调色；状态用常见的服务可用性语汇：绿色正常、红色异常、琥珀色等待、灰色无数据，圆角竖条心跳和可用率胶囊。浅色和深色都有，默认跟随系统，侧栏底部可切换。网页标题、图标和托盘图标都是 lgmon 的“四根心跳竖条”标识。

左侧只有：面板列表（每个面板前的圆点是整体状态，异常数红字）、“新建面板”、内网里别人给我看的面板（有时才出现）、告警、内网（待处理申请数）、设置。底部是实时连接（点一下刷新）、搜索（Ctrl K）、深浅色和波西米亚（Ctrl J）。手机上侧栏收进左上角菜单。

- 首页就是第一个面板；一个面板都没有时显示欢迎页，起个名字就能新建（默认“我的服务”），也可以直接把一段话交给 Agent，它加第一个服务时会自动建面板。
- 面板（`/#/boards/<id>`）：标题、简介，“添加服务”和列表 / 卡片 / 关系切换（每个面板记住）。上方小看板是服务数、子服务数、正常（含等待数）、异常和 24 小时可用率，有异常时异常格变红。列表每行：展开箭头（有子服务时）、可用率胶囊（颜色是现在的状态）、角色图标和名称、下面一行是说明（没有说明时是监控对象；异常时显示原因；后面写子服务数和“用到 N 个服务”）、24 小时心跳条、响应时间；整组异常排在最前并默认展开。主服务的名字加粗、图标大一号；展开后子服务挂在一条从主服务图标往下的细线上，像文件树，每个子服务一个拐角，最后一个收口（U10）。点行展开子服务，点名字进入详情；网址和网页类端口服务的名字旁有一个“打开”小图标，在新标签页打开它的访问入口（卡片标题旁和服务详情右上角也有，详情里显示“打开 域名”）。没有入口的网址或端口服务在详情右上角有“添加访问入口”，编辑服务时可以填对外的域名，留空就按网址或端口推断。“关系”视图（U10）把面板画成依赖关系图：从上往下，人直接用到的服务在上，它们依靠的隧道、网关、数据库在下；每个服务是一张带角色图标、名字和状态点的小卡片，子服务用细灰线挂在主服务下，依赖是带箭头的彩色线，16 种关系（依赖、调用接口、读写数据、读取、写入、经由、转发到、触发、发送消息、消费消息、认证、双向同步、复制到、备份到、故障切换到、监控）各有颜色、线型和箭头：实心箭头是直接使用，空心箭头是异步消息或故障时才用，菱形是数据，圆圈是认证和监控，方块是复制和备份，双向同步两端都有箭头；可选依赖（它坏了服务还能降级运行）画成细虚线并标“可选”。一个服务连出或连入多条线时，线在卡片边上错开出入；线上的关系和补充说明会沿着自己的线找不压住服务、也不压住其他说明的位置；鼠标移到线上只亮这一条，并显示“A → B：关系”。跨过一层以上的线绕开中间的服务。面板的关系图里，没有自己依赖的正常子服务收进主服务底部的“N 个子服务”小标签（一格小色条一个子服务），点开再画出来，异常的子服务始终画出来。面板外被用到的服务也画出来，虚线边框、标“在别的面板”。鼠标移到一个服务上，只亮它的上下游。图下面是图例。还没有任何依赖时，下方是一张 Agent 卡片“让 Agent 梳理依赖关系”，那段话让 Agent 查清服务之间谁用谁、先列给你确认，再写说明、角色和依赖，值得记的写成文档。卡片视图（U5-04）里每个服务可以用不同样式：心跳（可用率、24 小时心跳、响应时间，默认）、极简（大状态点和一句话）、可用率环（24 小时环和 7/30 天）、响应曲线（24 小时响应时间和当前值）、30 天（30 个日格，适合计划任务）、大数字（当前响应或可用率）；子服务在所有样式里都是卡片底部带状态点的小标签。鼠标移到卡片上，右上角出现样式按钮可以直接换；面板更多菜单的“卡片样式”打开样式库，六种样式用同一个示例服务展示并写明适合什么，可设为面板默认或给单个服务指定。样式保存在 boards.yaml 的 cardStyle / cards，内网里别人看到的也是同样的样式。超过 8 个服务时出现筛选框。不在任何面板上的服务会提示“放进这个面板”。
- 添加服务只有一个入口（U5-02）：面板右上角“添加服务”、服务详情“添加子服务”都打开同一个对话框，空面板直接内嵌同样的内容。默认是交给 Agent：一张 Agent 卡片（U6-02），一句说明它会做什么、“复制这段话”、默认收起的“显示这段话”和实时接入状态。话里不需要填写任何内容，已带面板 ID 或父服务 ID；Agent 会先问你要监控什么。接入步骤就在这段话的开头，手动接入只在“设置 → Agent”里。对话框右上角“手动创建”切到点选界面：端口 / 网址 / Windows 服务 / 进程 / 计划任务五类，除网址外都从这台电脑正在运行的列表里搜索点选（已监控的灰掉），名字自动带出，可选“挂在哪个服务下面”；那里右上角“交给 Agent”切回。只读时点“手动创建”会说明怎么获得修改权限，Agent 话术照常可用。服务列表下方和服务菜单里不再放话术。
- 服务详情（`/#/monitors/<id>`）：面包屑（面板 / 主服务 / 本服务）、角色图标、名字和状态徽章，下面是说明（没有说明、又有修改权限时是一个“加一句说明”的按钮），再下面是监控对象和电脑；24 小时 96 格大心跳条、可用率与响应时间小看板（没有探测的服务改显示 7 天可用率和最近检查，HTTPS 显示证书剩余天数）、30 天日条、响应时间面积图、子服务、依赖关系（U10，有依赖时才出现：这个服务上下游的小图，下面两列“它用到”“用到它的服务”，写关系和补充说明）、事件、文档、“什么时候告警”。文档（U10）像产品文档那样排版：正文一栏，宽屏时右侧是“本页内容”目录；代码块上方写语言、带“复制”；“> **注意**”“提示”“警告”开头的引用是带图标的提示框；表格有边框；`[[服务ID]]` 显示成带角色图标和状态点的服务链接（找不到的服务显示成虚线标签）；语言写 deps 的代码块画依赖关系图（空块画本服务的上下游，写几个服务 ID 画它们之间的关系）。有修改权限时右上角“编辑”打开编辑框（Markdown 和预览两个标签，可删除文档）；还没有文档时是一张“让 Agent 写这篇文档”的卡片。事件（U5-03）以异常时段为单位，覆盖本服务和全部子服务最近 7 天：先一句总结（几次异常、合计多久），再按服务分组（本服务在前，子服务按树序），每条写明服务名、开始时间（年-月-日 时:分:秒）、结束时间、持续时长、原因和期间触发的告警；正在发生的标“进行中”并显示已持续多久。恢复后只记持续满 1 分钟的异常（与 U4-11 一致）；不伴随异常的告警（例如证书快到期）也单独列出。每组默认 3 条，其余点“展开其余 N 条”。右上角“添加子服务”；更多菜单里是“编辑”（改名字、说明、它是什么〔角色，可选“自动判断”〕、挂在哪个服务下面；要换检查地址或告警等待时间时，编辑框底部给一段交给 Agent 的话）和删除（有子服务时提示一起删除）。
- 内网（`/#/lan`）：见 [内网共享](teams.md)。顶部是本机账户（头像和昵称），下面是内网可见开关、部门、申请和授权。别人同意后的面板出现在侧栏“别人的面板”（按主人所在部门、再按人分组，头像和昵称），打开后和自己的面板一样有列表、卡片和关系三种视图，点进服务能看详情、事件、告警规则和文档，只是不能改（`/#/lan/remote/<id>`、`/#/lan/remote/<id>/monitors/<服务ID>`）。
- 设置（`/#/settings/<分组>`，U8）：像 Claude、ChatGPT 的设置一样，左边一列分组，右边一次只看一组；手机上分组变成顶部一排可横向滑动的标签。每一项是一行“名称和一句说明 | 控件”，放在圆角卡片里。分组：通用（配色：跟随系统 / 浅色 / 深色；关于 lgmon：版本、更新、使用说明；自定义视图）、通知（已启用的渠道，接入飞书或管理通知，告警卡片模板）、电脑（每台电脑的 CPU、内存、配置下发状态、离线缓存，资源与启动项、从服务开关导入；浏览这台电脑）、Agent（接入的 Agent：每个一行，图标、名称、版本、令牌、连上多久、调用了几次，右侧“已连接”信号或“几分钟前断开”；复制给 Agent 的话；各客户端的详细接法）、波西米亚（两把密钥和模型、让 Agent 帮忙配置、命令行和打开波西米亚）、访问权限（现在的权限和获得更多权限）。`#/settings` 默认打开“通用”，旧链接 `#/settings/assistant` 仍落到波西米亚。
- 页面顶部提醒：通知暂停、采集器配置未更新、电脑时钟偏差、离线缓存不足 24 小时、规则错误，只在有问题时出现。
- 旧地址继续可用：`#/boards/<id>` 找不到面板但有同 ID 的自定义视图时打开该视图；`#/views`、`#/alerts`、`#/notifications`、`#/hosts/...`、`#/explore`、`#/connect`、`#/teams` 仍在，只是不占主导航。

本机网页权限：以本人身份运行（个人目录）时，在这台电脑上直接打开网页即可添加服务、建面板、处理内网申请（config），界面上不出现任何权限字样。只能查看时（以系统服务运行，或从别的设备用 read 令牌打开），需要修改的按钮照常显示，点了才弹出“需要修改权限”：说明为什么现在只能看，并给出办法（本机在 settings.yaml 写 `localAccess: config`，或按本机实际路径生成令牌粘贴进来，令牌只保存在这个标签页）。修改设置和密钥需要管理员令牌，同样在被挡住时说明。设置里的“访问权限”一组写明它只在这两种情况下有用。

## 页面与数据

有自建或加入团队后，面板页出现“团队共享”分组与“团队与分享”入口。负责人用 admin 管理成员和分享；成员用 read 查看授权卡片，支持时间、主机选择及手机/深浅色，失联或撤销后清空旧数据。首次设备加入可直接打开 `/#/teams/join`，默认游客页面不显示团队入口。详见 [团队共享](teams.md)。

告警行的“诊断包”进入 `/#/alerts/<id>/diagnostics`，read 即可查看、刷新、复制交接文本并下载同一 JSON。手机和深浅色均支持，复制不可用可手动选择文本。只读范围、数据完整性和字段隐私见 [诊断包](diagnostics.md)。

| 页面 | 入口与出口 | 数据与状态 | 阶段 |
|---|---|---|---|
| 总览 | `/`，主机卡进入详情，告警区域进入告警页 | collectors、targets、firing alerts、通知配置；只读 SQL 按索引取各主机最后一条系统指标 | M1-13 |

## 批处理任务（U12）

任务在面板里和其他服务一样占一行：最左边的状态取最近一天有消息的记录（成功为正常；失败、部分失败、漏跑为异常；其余等待），说明写“11月18日 成功 · 全部阶段成功”，原来心跳条的位置显示那一天的状态。事件文件读不了时，说明换成“事件文件读不了：原因”。

点进去（`/#/monitors/<任务ID>`）不再显示 24 小时心跳、可用率和响应时间，而是：

- **每日记录**：最近 30 天一天一格（成功绿、失败/部分失败/漏跑红、结果未知黄、运行中蓝、未启用斜纹），点一格跳到那一天。下面是最近 14 天的列表（“显示 30 天”看更多），连续 3 天以上未启用合成一行。最近一天有运行的记录自动展开。
- **展开一天**：先并排两块，“生产通路现在”（production 里那些监控当前是否正常）和“本次生产取数”（这一天最近一次运行的 fetch 阶段），两者互不替代；然后按时间倒序列出每次运行（手动补跑在前，之前失败的那次保留），每次有阶段时间线（开始、结束、用时、进度、错误摘要、回执；上传成功没有回执会标出“不算成功”）和小时分区数据表（区域、小时分区、独立收件数、独立发件数、收件数据条数、发件数据条数、gz 文件数、压缩大小、目标目录、校验、上传）。表格在手机上横向滚动。
- **数据来源**：接口上报时提示用 `lgmon job key <任务ID>` 生成密钥；文件来源显示哪台采集器读哪个文件、能否读取、最近一次问题和最近收到事件的时间。
- 阶段时间按北京时间显示；小时分区国内按 UTC+8、海外按 UTC+0，都带年份。服务关系、文档和子服务照常显示；任务没有告警规则一节。

## M1-14 控件绑定

五步网页向导复用 setup 的检查、测试发送和保存渠道逻辑。首次填凭据需要 admin，权限不足给出管理员令牌和 CLI 接入两种办法；config 可操作已保存应用。凭据验证后清空 Secret，不保存在浏览器存储。机器人和权限自动检查，群每五秒刷新，可同时选择多个群，各选模板、告警范围和规则，规则默认全选。确认收到前不写渠道；“没收到”列排查步骤，十秒后重发。关闭或离开页面丢弃本页收件状态，重新进入要重发。

保存先重新确认群成员关系，再合并渠道与规则。全部告警在新建时省略 filter，重置已有 filter 时显式传 {}；未修改的自定义筛选条件省略以保留。所选规则级别不在范围内时要求取消勾选，不静默删规则。规则写入失败显示已保存渠道的真实状态，链接到规则通知设置补充。服务端不记录网页确认状态，配置令牌原本就能写配置。

## 开发与验证

## 波西米亚（U5-05）

波西米亚是 lgmon 里的助手，标识取自本人的波西米亚（墨色云与气泡、陶土色核心，思考时转动）。它像一个熟悉这里的同事：问服务现在怎么样、最近哪里出过问题、为什么告警、lgmon 怎么用，它直接回答；也可以让它动手改已有的东西（U7）。

- 它知道你在看哪一页，也在提问时就拿到了整体情况（电脑、服务和状态、告警、面板），问现状不用再查；不会让你“去面板看看”，也不贴 http://127.0.0.1 这样的地址，要带你去别处时给站内链接。说话先给结论、正常的一句带过，不罗列正常的服务、不加表情、结尾不追问“要不要我帮你”。
- 它用的是和 Agent 一样的 MCP 工具（同一份定义、同样的校验），权限和你当前的网页相同，不会更多：改已有服务的名字和挂靠（edit_monitor）、换卡片样式和调整面板、删除服务、新建或删除面板和图表页、确认和静音告警、飞书和卡片模板、内网共享、团队与分享、远程重启已授权的服务。lgmon 的用法用 search_help 在内置说明里找（百炼向量模型找段落、rerank 排序）。
- 它不能添加新服务（需要查看这台电脑，交给能访问电脑的 Agent，从面板的“添加服务”开始），也不直接改配置文件。
- 删除、撤销、对外发消息、打开局域网可见、重启服务、邀请和分享之前，对话里会出现一张确认卡片：写明要做什么、对象和后果，点“确认”才执行，点“取消”或 3 分钟没回答都不执行。改完的东西列成改动卡片，点开去那一页。

面板在右下角，标题下的细线在思考时流动。回答进行时逐条显示它在看什么；答完收成一行“查了 N 项 · 改了 N 处 · 用时”，点开看明细；回答下面可以复制或重新回答。欢迎页有四个建议问题（现状、排查、动手、分享）。输入框下面不放提示文字，Enter 发送、Shift+Enter 换行写在发送按钮的提示里。没配置好时不报错，而是列出还差的两项（DeepSeek 的 API Key、百炼的 API Key），给出“去设置里填写”、一段交给 Agent 帮忙配置的话和本机命令 `lgmon assistant set`。

设置里的“波西米亚”一组（U5-06，U8 改为卡片）：两张卡片，DeepSeek（回答问题）和阿里云百炼（查说明用的向量模型和 rerank）。每张右上角显示密钥是否已保存；填密钥（保存后只显示“已保存”，要换时粘贴新的）、选模型（DeepSeek 的模型列表来自账号本身；百炼的两个模型折叠在“一般不用改”里），点“保存并测试”：先用一次小请求验证，通过才保存并显示“已连通”，失败显示原因、什么都不写。旁边有一段“让 Agent 帮我配置”的话（Agent 用 get_assistant / configure_assistant，密钥由本人提供）和本机命令。保存只需修改权限：以本人身份在这台电脑上打开的网页就能直接配置，不再要求管理员令牌。面板里的“去设置里填写”直接跳到这一节。

- **本机账户**：每台电脑第一次启动时自动有一个账户，头像随机取自内置头像（fiora，MIT），昵称取旧版设置过的内网名字，没有就随机“形容词的动物”；内网里别人看到的是头像和昵称，不显示电脑名。“内网”页顶部的账户卡片：点头像随机换一个、“上传头像”（裁成 160px 正方形，小 GIF 保留动画）、“改昵称”。小窗口右上角也是本机头像，点开是一个小菜单：头像、昵称、所在部门、内网是否可见，以及随机换头像、修改头像和昵称、内网与部门、设置。

- **卡片**：有子服务的卡片把子服务收进一条矮的状态条（每个子服务一格颜色和“N 个子服务 · 全部正常”），点开才是标签，异常的子服务收起时也显示；换卡片样式立即生效，保存在后台进行，失败会换回去；卡片标题用按角色识别的彩色图标；名字旁的“访问 ↗”小按钮打开访问入口。
- **加载**：页面脚本还没加载完时显示 lgmon 的启动画面；在本机打开时先显示上一次看到的数据（7 天内有效），后台同时刷新，读不到时小窗口会说明显示的是多久以前的状态；共享面板也保存最后一份并标出几秒前更新；常用页面的代码在空闲时预先下载；正在读取的地方是带微光的骨架屏。
- **返回**：每个页面顶部有“← 返回 上一页的名字”，按这个窗口里走过的页面返回，直接打开的页面返回它所在的面板。
- **历史告警**：告警页下方固定是“历史告警”，按天分组，每条有开始→恢复时间、持续多久和是否确认，可切换 24 小时 / 7 天 / 30 天，点一条看当时的事件。
- **文档编辑**：编辑文档的对话框几乎铺满窗口，宽窗口里左边写、右边实时预览；关系图按给它的宽度缩小（最小一半），缩小后右上角可以“全屏查看”（Esc 退出），也可以把整张图复制成 Markdown（服务表、关系表、子服务和 mermaid 图）或纯文本。
- **交给 Agent**：所有提示词改成分节的结构，写明要调用的工具和参数格式，减少 Agent 试错；关系图有单独的完整指引（先只读地收集证据、按对照表选关系、先给本人确认再写入）。Agent 卡片的“其他用途”打开从底部滑上来的面板：照看服务、加服务、梳理依赖关系、查问题、调整告警、告警发到飞书、安装 lgmon skill（一份几 KB 的操作手册，Agent 存下后以后照着做）。
- **波西米亚**：桌面上拖标题栏移动、拖边或角改大小、标题栏按钮或双击在大窗口和原来大小之间切换，位置记在本机（和留白里的一样）；开场推荐先放现在要紧的（正在异常的服务、正在看的页面、同事的面板），其余从能力示例里随机挑，可以“换一批”；回答进行中 Enter 插话（停下当前回答马上问新问题）、Ctrl+Enter 排队（输入框上方显示，可撤回）。知识库包括使用说明、每个服务的资料和本人选定的服务文档，按意思和关键词一起检索，设置里可以逐篇选择文档是否向量化；文档改动后只更新改了的段落。没有自己的 DeepSeek 密钥时，可以用已配对同事共享的模型，窗口顶部写明是谁共享的。
